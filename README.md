О проекте:
NEXUS - это MVP цифровой среды, объединяющей все необходимые инструменты для комфортного прохождения основного этапа хакатона. Платформа избавляет участников от необходимости переключаться между десятками вкладок, собирая всё в едином минималистичном интерфейсе.
Дизайн выполнен в премиальном темном стиле с акцентами медного/терракотового цвета, что обеспечивает комфортную работу даже ночью и снижает нагрузку на глаза.

Ключевые реализованные возможности (в рамках MVP):
1. Витрина хакатонов и Регистрация: Выбор мероприятия и динамическое формирование команды (ввод ФИО капитана и участников).
2. Дашборд: Актуальная информация о статусе этапа, составе команды и условии кейса.
3. Рабочее пространство (Командная работа):
Kanban-доска: Создание задач, перемещение по статусам («К выполнению», «В работе», «Готово»).
Умное распределение задач: Возможность назначить задачу на конкретного участника при создании, либо оставить её "Свободной" - тогда любой член команды может нажать кнопку «Взять себе».
Командный чат: Обмен сообщениями в реальном времени (демо-режим).
4. Образовательный трек: Доступ к обучающим видео и документам.
5. Расписание: Таймлайн мероприятий с возможностью перехода на внешние трансляции (Zoom, видео).
6. Сдача проекта: Форма загрузки финальной презентации и ссылки на репозиторий.
Технологический стек:
Основа: HTML5, CSS3, Vanilla JavaScript (без использования тяжелых фреймворков для максимальной скорости загрузки).
Стилизация: Кастомная минималистичная темная тема с терракотовыми/медными акцентами (написана с использованием современных возможностей CSS/Tailwind классов).
Архитектура: SPA-подобное поведение (Single Page Application) с помощью JavaScript для бесшовного переключения между экранами без перезагрузки страницы.
Иконки: Векторные SVG.

Запуск проекта (Инструкция для ревьюеров)
Проект максимально прост в развертывании и проверке. Никаких дополнительных установок баз данных, Node.js или выполнения скриптов не требуется.

 Тестовый сценарий (User Journey) для проверки жюри

Для оценки работоспособности основного сценария (в соответствии с критериями), пожалуйста, выполните следующие шаги:

1. Вход: На стартовом экране выберите любой доступный хакатон (нажмите «Выбрать»).
2. Регистрация: Введите произвольное название команды (например, "CyberTeam"), ФИО капитана и ФИО участников, затем нажмите «Зарегистрировать команду».
3. Дашборд: Убедитесь, что вы попали в пространство хакатона и система подхватила введенное название команды и количество участников.
4. Командная работа (Доска и Чат):
Перейдите во вкладку «Команда» (в меню слева).
Создайте новую задачу, оставив её «Свободной» (Не назначен).
Найдите созданную задачу в колонке «К выполнению» и нажмите кнопку «Взять себе» — задача закрепится за вашим именем (именем капитана).
Протестируйте отправку сообщений в чат.
5. Обучение и Расписание: Перейдите во вкладки «Обучение» и «Расписание», чтобы оценить верстку и подачу материалов (навигация работает без перезагрузки).
6. Сдача решения: Перейдите во вкладку «Сдача проекта», заполните обязательные поля (Название и Ссылка) и нажмите «Отправить решение». Убедитесь, что появился экран успешной сдачи.
